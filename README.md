A hands-on, in-person introduction to [Claude Code](https://code.claude.com/docs/en/overview) from NC State University
Libraries' Data Science Services, part of the *Data Science Special Topics* series. First run: Thursday, October 15,
2026, 2:00–3:30 pm, D. H. Hill Jr. Library.

**Workshop site:** <https://ncsu-libraries.github.io/agentic-coding-with-claude/>, or the short link
<https://go.ncsu.edu/dss-claude>

## What attendees do

Everyone installs Claude Code, then takes one starter folder around the agent loop: **read → plan → act → check**.
They ask for a one-page dashboard from a messy spreadsheet. In the plan step, they predict whether Claude will ask
about a rule only they know, or assume. Then they catch the assumption before any code exists. A known answer and
`/goal` check the result. Project memory (`CLAUDE.md`), a reusable skill (`/house-style`), `/rewind` and a share link
make it stick. The last ten minutes are for building something of their own.

There are two interchangeable activities with the same eight steps. One runs live; the other is self-guided.

| Activity | The data | The rule Claude can't see | The planted problem |
| --- | --- | --- | --- |
| [Study-room bookings](site/activity/study-rooms.qmd) | 10,279 rows (9,930 bookings), Jan 2024 to Sep 2026 | Fiscal years, July to June | Rows repeated by an export glitch |
| [Campus café sales](site/activity/cafe.qmd) | 264 days × 10 menu items, Aug 2025 to May 2026 | The exam-week dates | A latte rung up at $45.00 |

All data is synthetic, generated by `tools/make_data.py`.

## What's here

| Path | What it is |
| --- | --- |
| `site/` | The Quarto website: start page, setup guide, both activities, cheat sheet, finished examples, and both slide decks (`site/slides/`) |
| `starters/` | The two starter folders attendees download, as zips, from the site |
| `examples/` | Each activity's finished folder from a rehearsal run: dashboards, `CLAUDE.md`, the skill |
| `tools/` | Data generator, zip packaging, screenshot and video scripts |

The facilitation guide, rehearsal notes and answer keys aren't part of this repository.

## Build it locally

You need [Quarto](https://quarto.org) 1.10 or later. RStudio ships one at
`/Applications/RStudio.app/Contents/Resources/app/quarto/bin/quarto`.

```bash
bash tools/package.sh   # zips the starters and examples into site/downloads, copies example pages
quarto render site      # builds site/_site, including both decks
quarto preview site     # or serve it locally while editing
```

Other scripts:

| Command | What it does |
| --- | --- |
| `uv run --with numpy --with pandas python tools/make_data.py` | Regenerates both datasets and `instructor/answer-keys.json` (seeded, so identical every run) |
| `node tools/shoot.mjs list.json` | Screenshots pages or slides with headless Chrome |
| `node tools/record-tour.mjs` | Records the captioned walkthrough video into `site/video/` |
| `python3 tools/check_links.py [--web]` | Checks every link and image in the rendered site; `--web` also requests external URLs |
| `bash tools/demo-folder.sh study-rooms` | Makes a fresh demo folder outside the repo and clears its Claude Code memory |

If the site moves to a different GitHub owner or repo name, search for `ncsu-libraries.github.io` and
`NCSU-Libraries/agentic-coding-with-claude` and change both. Then point the go link `go.ncsu.edu/dss-claude` at the new
address: the slides show it, and their QR code (`site/images/qr-session.svg`, made by go.ncsu.edu) encodes it.

## Publishing

Pushing to `main` runs `.github/workflows/deploy-pages.yml`. It builds the zips, renders the site, and deploys it to
GitHub Pages. Set **Settings → Pages → Source** to **GitHub Actions** *before* the first push, or the first deploy
fails; if it did, re-run the workflow from the **Actions** tab.
